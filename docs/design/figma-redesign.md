# Workspace redesign

The redesign uses the connected [PRM Figma file](https://www.figma.com/design/7sh6Lf9cuSxgbso7xyaorb/Untitled). Access and edits were performed with Figwright MCP.

The component page is organized into 27 named sections, with 64px gaps inside sections and 160px between them. It currently contains 916 items inside sections, including 245 component sets, on a canvas about 44,000 × 28,000px. Its vertical extent remains about 94% smaller than the former layout, despite the additional response and monster-editing templates. The largest comparison set uses a compact arrangement, reducing its height from 13,755px to 3,271px while preserving all 32 variant dimensions. Read-back checks found no overlapping items/sections or content outside section bounds. New families and review boards must be packed into these sections instead of continuing the former vertical coordinate sequence.

## Foundations

`src/assets/scss/_variables.scss` owns the palette and spacing. Figma variable code syntax references the existing CSS properties. Surface, input, and panel tokens can share a color while retaining their separate semantic roles.

Manrope and IBM Plex Sans are served locally from `public/fonts`; their OFL license files are included. The dark palette is an application adaptation of the new light design; the original screen frames specify the light theme.
